# تثبيت تطبيق جدول مساقاتي

هذه نسخة PWA قابلة للتثبيت على Android وiPhone.

## قبل التثبيت
يجب رفع محتويات هذا المجلد إلى استضافة تدعم HTTPS (مثل GitHub Pages أو Netlify).
لا يكفي فتح index.html مباشرة من مدير الملفات؛ يجب تشغيله من رابط HTTPS حتى يعمل التثبيت والعمل دون إنترنت.

## Android
1. افتح رابط الموقع في Chrome.
2. اضغط «تثبيت التطبيق» إذا ظهر الزر، أو من قائمة Chrome اختر «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
3. افتح التطبيق من أيقونته.

## iPhone
1. افتح الرابط في Safari.
2. اضغط زر المشاركة.
3. اختر «إضافة إلى الشاشة الرئيسية»، ثم «إضافة».

## الملفات
- index.html: واجهة جدول المساقات.
- manifest.webmanifest: تعريف التطبيق وأيقونته.
- service-worker.js: التخزين المؤقت ودعم العمل دون إنترنت بعد أول زيارة.
- icons/: أيقونات التطبيق.
